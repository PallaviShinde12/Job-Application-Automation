# Job-Application-Automation
An automated Job Application Tracking System using Python, Gmail API, Excel, and Power BI to extract job application emails, maintain an Excel tracker, and visualize application insights
## Technologies Used

| Category | Technology |
|---|---|
| Programming Language | Python |
| Email Integration | Gmail API |
| Authentication | Google OAuth 2.0 |
| Data Processing | Pandas, OpenPyXL |
| Spreadsheet | Microsoft Excel |
| Data Visualization | Power BI |
| Development Environment | VS Code |
| Version Control | Git & GitHub |

## Key Features

- Gmail integration using Gmail API.
- Automated extraction of job application emails.
- Email labeling and filtering.
- Extraction of candidate name, job role, experience, and application status.
- Automatic Excel tracking.
- Power BI dashboard for application analysis.

## Project Workflow

1. Connect Gmail using Gmail API and Google OAuth 2.0.
2. Retrieve job application emails.
3. Extract relevant information from emails.
4. Store extracted information in an Excel tracker.
5. Visualize application insights using Power BI.

## Project Outcome

Developed an automated system to simplify job application tracking, reduce manual work, and visualize job application insights.
